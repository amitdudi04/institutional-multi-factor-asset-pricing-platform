## Selected zero-cost stack

The selected architecture is Alpha Vantage Free lifecycle evidence + SEC EDGAR issuer/PIT filing evidence + HF Data Library CC BY 4.0 daily market evidence + FRED DGS3MO + the Kenneth French Data Library. It is a public/free-data empirical validation, not CRSP/Compustat replication.

HF Data Library attribution must include: Elkassabgi, A. (2026), *HF Data Library: Free 1-Minute Intraday U.S. Equity Data*, Zenodo, DOI 10.5281/zenodo.19501605. For post-March-2022 evidence it must additionally state: “Data provided for free by IEX. By accessing or using IEX Historical Data, you agree to the IEX Historical Data Terms of Use.”

The canonical HF version is `clean`. Official documentation states that both versions use source-provided split- and dividend-adjusted prices; `clean` then removes outside-hours, non-positive/zero-volume, invalid-OHLC, duplicate, extreme-return, and Brownlees-Gallo outlier bars while preserving gaps. Daily files are upstream aggregates of those one-minute bars. The platform therefore does not apply a second corporate-action adjustment. It preserves each row's `pitrading` or `iex` source marker because the March 2022 transition changes the feed from consolidated tape to IEX-only trading and creates a material volume/coverage break. HF is unsuitable as a complete historical-universe authority, and long-horizon results require explicit survivorship-bias disclosure.

The 2026-08-12 public inventory was reconciled one-to-one between `/v1/symbols` and the official ticker metadata: 1,391 records, 822 selected `Stock` records and 569 policy-rejected `ETF` records. The dated manifest, record-level selection reasons, retrieval time, and both upstream checksums are retained under ignored runtime metadata; the dataset itself is not committed.

## Live defects discovered

- `FD-001` (High, closed in code): HTTPX informational logging rendered an Alpha Vantage query credential. The affected credential was revoked locally, no repository/runtime file contained it, HTTPX/HTTPCore informational logging is now suppressed, provider URLs are redacted in exceptions, and regression tests enforce both controls.
- `FD-002` (Medium, closed): Alpha Vantage returned exact duplicate lifecycle rows. Raw evidence remains immutable; exact duplicates are collapsed only after recording `source_duplicate_count`. Distinct issuers sharing a ticker remain separate.
- `FD-003` (Low, open external): Alpha Vantage free-tier quota responses interrupt batch acquisition. Completed snapshots are cached; error JSON fails closed and no premium upgrade is used.
- `FD-004` (Medium, open upstream): HF Data Library TWTR and ATVI daily Parquet files omitted the citation and IEX-attribution metadata present in validated AAPL/MSFT/SPY/FB/GOOG/GOOGL files. The platform rejected and quarantined them; they are excluded until upstream provenance is repaired.
- `FD-005` (High, closed): an HF legacy `FB` ticker file continued beyond the verified 2022-06-08 ticker interval. Mandatory requested-date clipping and effective-dated mapping resolution now prevent post-change rows from being attributed to the legacy identity.
- `FD-006` (High, closed in code; upstream data remains excluded): GOOG and GOOGL each contained an approximately 95.25% adjusted-close discontinuity exactly at the PiTrading/IEX splice on 2022-03-07. This invalidates the upstream splice-continuity claim for those files. Provider-specific continuity validation now fails closed at a source transition above 50%; affected publications are demoted and the symbols remain excluded pending corrected upstream evidence.
