# Admissions Project Summary

I built and empirically exercised an institutional-style quantitative research platform from immutable data ingestion through authenticated API, dashboard, and reports. The final free/public-data study screened 822 candidates, accepted 487 defensibly bounded equities, processed 715,447 daily market observations, estimated 47 of 48 governed factors, compared five asset-pricing families, ran eight long-only portfolio methods under costs frozen before performance, and evaluated eight purged walk-forward ML models.

Real data exposed cross-phase defects in benchmark calendars, sparse regression handling, explainability routing, prediction-to-return mapping, publication lineage, and monthly sampling. I corrected them with regression tests without relaxing identity, temporal, or governance controls.

The result is scientifically honest rather than promotional. Multifactor fit improves in-sample and portfolio costs are material, but ML confidence intervals include zero and stable after-cost value is not established. Missing equity-issuance inputs remain non-estimable rather than fabricated. The project is reproducible academic research—not financial advice, proprietary-data equivalence, or a production trading claim.
