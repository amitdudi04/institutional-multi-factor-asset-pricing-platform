# Project Case Study

## Problem

The platform needed a broad, reproducible US-equity study without fabricating historical identity, shares, fundamentals, transaction costs, or model performance. The challenge was to connect real free/public data through factors, asset pricing, portfolios, ML, and delivery while preserving fail-closed evidence boundaries.

## Approach

All 822 HF candidates entered a restart-safe cheap-to-expensive screening waterfall; 487 passed. Phase 2 constructed 48 governed factor definitions, leaving one honestly non-estimable. Phase 3 evaluated five configured model families. Before any Phase 4 performance was examined, LOW/BASE/HIGH one-way costs were frozen at 5/10/20 bps. Phase 5 then bound exact upstream publication identities and used purged monthly walk-forward evaluation across eight models.

## Defects found by real data

Real scale exposed sparse formation-date and rolling-window failures, a security-specific benchmark-calendar bug, baseline explainability misrouting, an allocator assumption that every return asset had a prediction, incomplete Phase 4 identity binding in ML manifests, and daily feature pseudo-replication under a monthly research design. Each received a regression test and remediation without weakening the analytical rules.

## Outcome

The final chain authenticates 487 equities, 47 estimable factors, five asset-pricing families, eight portfolio methods, eight ML challengers, and four report formats. The scientific result is restrained: multifactor in-sample fit improves, costs matter, constrained portfolios create trade-offs, and ML fails to show stable incremental after-cost value. The project demonstrates that institutional research quality includes negative and inconclusive results, immutable lineage, and refusal to turn missing inputs into favorable assumptions.
