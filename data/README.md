# Local Data Area

This directory is local storage for research data. Empirical files are ignored by Git. Raw provider and owner-supplied files are preserved without in-place modification by the application and remain subject to their source terms; the repository MIT License does not grant rights to external data.

Tracked schema definitions live in the Python package and `docs/DATA_CONTRACTS.md`. Never place credentials here. Never delete raw or quarantined artifacts through normal ingestion.
